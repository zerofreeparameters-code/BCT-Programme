5. Axis alignment: easy-axis / Zeeman potential, or pinning n = z on every shell
==============================================================================
  (i) A potential D(1 - n_z^2) or h(1 - n_z) has no derivatives: it adds nothing to c_F and scales as
      L^3 under x -> x/L, so it cannot stop Derrick collapse; it only caps the knot size from above.
      It gaps the magnon (omega = eps_k + 2D/hbar-type gap): still no photon-like mode.
  (ii) Pinning n = z on each shell is the Q4(iv) grip term: it makes H well-defined per sphere,
      but does not touch c_F, the slaving of a, or the Higgs mass.
  (iii) pinned Hopf-1 knot in one sphere: |int f dV| / int |f| dV = 1.84e-15
      Each knot's twist field integrates to zero over its sphere, so aligning every knot along one
      axis gives no macroscopic twist field and no long-range mode; aligning the knot axes in space
      is a vector (T1u-type) order -> lattice anisotropy (Gate PROMOTE, CN-PROMOTE-02).
