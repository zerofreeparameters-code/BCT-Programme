2. 12-NEIGHBOUR LATTICE AT c/a = sqrt2 AND ITS GRAPH LAPLACIAN
==============================================================================
12 neighbours, all at distance a: 8 body (+-1/2,+-1/2,+-1/sqrt2), 4 in-plane (+-1,0,0),(0,+-1,0)
second moment sum_d d d^T = [4, 0, 0, 0, 4, 0, 0, 0, 4]  -> isotropic (= 4 I): k^2 term isotropic
8 body vectors alone (corpus gamma(k), z = 8): [2, 0, 0, 0, 2, 0, 0, 0, 4]  -> NOT isotropic (zz/xx = 2)
sum_d (k.d)^4 = A |k|^4 + B sum_i K_i^4 (cubic axes): {A: 3, B: -1}
lambda(k) = (1/2) sum_d (1 - cos k.d) = |k|^2 - |k|^4/16 + (sum_i K_i^4)/48 + O(k^6)
  quartic coefficient along [001]: -1/24  (nonzero, direction-dependent)
  quartic coefficient along [110]: -5/96  (nonzero, direction-dependent)
  quartic coefficient along [111]: -1/18  (nonzero, direction-dependent)
  => App E.0 Sec.3.1 conjecture ('k^4 coefficient vanishes under O_h') is FALSE for the
     nearest-neighbour lattice. For ANY finite-range lattice operator omega^2(k) is a
     trigonometric polynomial (real-analytic, periodic); if it equalled c^2|k|^2 on a
     neighbourhood of k=0 it would equal it everywhere, contradicting periodicity. Exact
     linearity is impossible on any lattice with finite-range coupling.
