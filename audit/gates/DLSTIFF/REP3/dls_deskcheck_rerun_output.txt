# 3. Route R2 kill test, symbolic: Maxwell coefficient induced by a dipole-coupled medium
P(E) = E*chi + P0    U(E) = -int P dE = -E**2*chi/2 - E*P0
coefficient of E^2 in U: -chi/2   (this is the induced Maxwell/epsilon term)
with P identically zero (STIFF, SC-STIFF-5: P0 = 0 and no polarisable charge => chi = 0): 0
=> a neutral medium with no dipole response induces no Maxwell term; beta cannot come from R2
   unless the run exhibits a nonzero chi from the pinned sources.

# 4. Route R3 reminder (Josephson-junction array analogue; no computation, a statement)
link coupling E_J = phase stiffness;  plaquette (loop) coupling = Phi_0^2/(2 L_loop), set by the loop
inductance L_loop, an independent scale. Identifying beta with the phase stiffness needs a derivation
