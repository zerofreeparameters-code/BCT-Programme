If at any point the runner learns the earlier outcome (from a file, a commit message, a memory entry, a past chat, or the operator), it must say so at once, name the source, and continue. The run is then recorded as **UNBLINDED** in the result header and is capped at CONJECTURE tier.

The operator must not hint at the earlier outcome, confirm or deny guesses, or react to intermediate findings until the result file is delivered.

## 3. Procedure

1. Hash-check the original card (§1). Then read it.
2. Execute the original card **exactly as written**: same question, same obstruction checks, same verdict set (SC-ALTER-1 to SC-ALTER-4), same stop conditions. Where this card and the original card conflict, this card governs only on corpus pinning (§1), forbidden actions (§2), the added step (§4) and deliverables (§7).
3. Write a fresh, independent check script for every obstruction check the original card requires. Exact arithmetic only (rationals, or exact ℚ(√2)). No floating point in any pass/fail decision.
4. Include one positive control: a known altermagnetic structure on a body-centred tetragonal magnetic lattice, showing that the script returns "translation fails, rotation-with-fractional-translation succeeds" for it. A script that cannot pass a known positive cannot certify a negative.
5. Search the pinned corpus. Record the search terms **before** running them, in the result file, and do not add terms after seeing hits without logging the addition and the reason.

## 4. Added step — space-group derivation for every near-miss

For **every** pattern found in the corpus that assigns different labels, handedness, orientation, occupancy or phase to the two sublattices (whether or not the source calls it magnetic), the runner must, from scratch:

1. Write the decorated structure explicitly: lattice vectors, site positions, and what sits on each site.
2. Test, in exact arithmetic, whether the two sublattices are related by (a) a pure lattice translation, (b) inversion about any point, (c) a rotation or rotoinversion combined with a fractional translation and **not** reducible to (a) or (b).
3. List the full set of symmetry operations that survive the decoration and state the space group, with its number, and the reasoning that fixes it. If two space groups remain possible on the information in the source, say so and give both.
4. State the consequence: degenerate (opposite-sublattice bands related by translation or inversion) or not.
5. Record the source's own date and where in the repository history the file first appears. A source that cannot be dated to ≤ 2026-09-30 is reported but cannot by itself support SC-ALTER-1.

A pattern may not be dismissed without this derivation. "Looks like a simple antiferromagnet" is not a derivation.

## 6. Stop conditions

Checked in this order.

- **SC-R-0 — hash mismatch.** The original card does not hash to the value in §1. Stop. Report both hashes. No verdict.
- **SC-R-1 — positive control fails.** The runner's script does not pass the control in §3.4. Stop. Report. No verdict.
- **SC-R-2 — corpus unavailable.** The pinned tree cannot be obtained with `audit/` excluded. Stop. Report. No verdict.
- **SC-R-3 — completed.** The runner reaches one of SC-ALTER-1 to SC-ALTER-4 under the original card. Report it with the evidence.

The runner does **not** compare its verdict with the earlier run. That comparison is made by the operator after delivery and recorded separately as one of:

- **MATCH** — same verdict, and no near-miss classified differently;
- **MATCH-WITH-DIFFERENCE** — same verdict, but a near-miss was found, missed, or assigned a different space group;
- **MISMATCH** — different verdict. Neither run is then authoritative; the disagreement itself becomes a ledger item and a third, adjudicating gate is pre-registered.
