3. **The N-class.** Every sub-1% result has the form (geometric value)·(1 + N·α₀) with N named
   after the fact. Eleven distinct N values found. The corpus has its own term for it.
   Gate PRED2 scored the collection at ≈0 bits against a null model.

## 1 — THE THEORY

A single complex scalar Ψ on a body-centred tetragonal lattice:

```
Ψ(x,t) = √ρ(x,t) · e^{iθ(x,t)}
```

One field. Two real components. No vector, no tensor, no spinor. This is not a restriction
imposed by the audit — it is what every written action in the corpus contains.

### 1.2 Action [PROVEN — present in App E, App J]

```
S = ∫ d⁴x [ J(∂_μΨ)*(∂^μΨ) − (J/4ξ²)(|Ψ|² − Ψ₀²)² ]
```

The void inradii are correct geometry. That is not in dispute.

## 3 — THE SHARP QUESTION, AND IT IS TESTABLE

**In this theory, do r_oct and r_tet do two numbers' worth of work, or one?**

α₀ enters only through ξ. ξ enters only as a length scale. And ξ depends on the void radii
**only through their product**:

```
ξ = 1/√(8·r_oct·r_tet)        product = 0.023273093451
                               ratio   = 1.843038997
```

If every observable in the minimal theory depends on r_oct and r_tet **only via their
product**, then the "two-radii, zero-parameter" geometry has collapsed to **one number** —
and one number fixing one length scale is the same epistemic situation as Λ_QCD = 220 MeV,
which the census closed as an input (INV-0120).

**If some observable depends on the ratio r_oct/r_tet independently**, the geometry is doing
genuine two-parameter work and the minimal theory has real content.

This is answerable by calculation, not opinion. **It is the test that decides whether minimal
BCT is a theory or a relabelled superfluid.**
